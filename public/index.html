  • настраивал подключение сервисов к базе данных, разделял права пользователей для разных микросервисов и ограничивал доступ сервисов к данным.

  • написал Github Actions пайплайны для автоматической проверки кода, непрерывной доставки и Zero Downtime развертывания микросервисов на сервере
  • написал конфигурацию для nginx сервера: проксирование на микросервисы, ssl сертификаты, кэширование, http2, сжатие http-ответов
